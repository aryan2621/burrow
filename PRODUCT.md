# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Tauri desktop shell, React, Tailwind and shadcn/ui (existing). Rendered in a webview on macOS, Linux and Windows.

## Users
Individuals who run AI agents on their own machine and want control over what each agent can reach. (Inferred from the repo; not yet confirmed by the owner.)

## Product Purpose
Burrow runs agents, each with its own sandbox, chosen folders and sites, and approval rules for risky actions. Local (llama.cpp) or cloud models. Success: a user creates an agent, hands it work, and trusts what it did.

## Capabilities and Constraints
Agents, chat, activity timeline with undo, tools, schedules, routines, memory, teams, model downloads. Must work on macOS, Linux and Windows. Light and dark.

## Product Principles
- Show what an agent can touch and what it did.
- Calm, dense, task-first; the tool disappears into the work.
- One accent, used for action and selection only.
